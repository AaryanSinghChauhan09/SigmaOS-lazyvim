# SigmaOS LazyVim

Neovim configuration optimized for SigmaOS with LazyVim distribution.

## Overview

SigmaOS LazyVim provides a pre-configured Neovim setup using the LazyVim distribution, optimized for SigmaOS development workflows.

## Features

- LazyVim distribution
- SigmaOS theme integration
- Key mappings for SigmaOS workflows
- LSP and formatting support
